# OkazuNOTE

## 誰の、どんな困りごとか
毎朝、弟と自分のお弁当を作らなければいけない母
おかずのレパートリーに困る
またいざ作ろうと思ったときに、材料や作り方から考えるのがめんどくさい
材料を把握したとしても、足りないものをわざわざメモするのは大変


## コア機能1つ
人気な料理数品を画面に表示する。その中から料理を選んでクリックすると材料、作り方が書かれたページが表示される。材料、作り方は完了した事項から消していくことができる。
